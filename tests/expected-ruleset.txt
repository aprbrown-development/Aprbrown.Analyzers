# The expected ruleset (#51): every setting the shipped config must contain, and nothing else.
#
# scripts/verify-package.sh reads build/Aprbrown.Analyzers.globalconfig out of the package it is
# handed and scripts/ruleset-diff.sh compares the two as a multiset of `key = value` lines.
# Comments, blank lines and spacing around = are ignored on both sides; every other line must match
# exactly, and any that does not is printed — `+` for a line only the shipped config has, `-` for one
# only this file has.
#
# This is deliberately a second copy of the shipped config. A test needs an expectation that does
# not come from the thing under test, so a change to the house ruleset — a rule added, removed or
# re-levelled, which ADR-0004 makes a versioned act — is made here and there both, and the diff on
# this file is what a reviewer reads. Never regenerate it from the shipped config: a copy taken
# from the file under test agrees with it by construction and checks nothing.
#
# The derivations behind each tier are frozen (spec §2.3), against Meziantou.Analyzer 3.0.123,
# StyleCop.Analyzers 1.2.0-beta.556 and SDK 10.0.110. The shipped config explains each tier at
# length; the comments here record only why individual lines are pinned as they are.
